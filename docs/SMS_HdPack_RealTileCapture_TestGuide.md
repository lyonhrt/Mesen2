## ?? **What the System Captures**

**Background Tiles:**
- **Complete 32-byte tile data** from SMS VDP pattern memory
- **Screen position** where tile will be rendered (x, y coordinates)
- **Palette information** (background vs sprite palette)
- **Tile attributes** (horizontal mirror, vertical mirror, priority)
- **VRAM address** for tile identification

**Sprite Tiles:**
- **Complete 32-byte sprite tile data** 
- **Sprite screen coordinates** from sprite attribute table
- **Sprite palette colors** (always high palette 0x10-0x1F)
- **Real sprite positions** during rendering

**HD Pack Format:**
- **Tile Data**: 64-character hex string of complete 32-byte SMS tile
- **Palette Colors**: 32-bit ARGB color value representing palette
- **Screen Position**: X,Y coordinates where tile appears
- **Brightness**: Fixed at 1.0 for now
- **Conditions**: Basic format for now (can be enhanced)
